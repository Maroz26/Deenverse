## Firebase Authentication dan Firestore

1. Di Firebase Console, aktifkan **Authentication → Sign-in method → Email/Password**.
2. Pastikan Firestore Rules membatasi setiap profil ke pemilik akun. Aplikasi menyimpan dokumen profil di `users/{uid}`:

   ```text
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

3. Username dipetakan ke alamat internal untuk Firebase Authentication; pemain tetap masuk dengan username dan password. Password tidak disimpan di dokumen Firestore. Karena alamatnya bukan email pemain, fitur reset password lewat email belum tersedia.
4. Akun lama yang masih ada di `localStorage` dapat dipindahkan ketika pemiliknya login di perangkat lama. Dokumen migrasi lama `users/{username}` berisi password teks biasa; hapus dokumen lama dari Firestore setelah akun berhasil dipindahkan. Jangan membuka rules Firestore secara publik untuk memindahkannya.
5. Jika data lama hanya tersisa di Firestore dan tidak ada lagi di `localStorage`, lakukan pemindahan lewat proses admin tepercaya sebelum menerapkan rules per-pemilik di atas; jangan mengaktifkan akses baca publik untuk username atau password.
